The 1.1 Activity Monitor has recovered C implementations for IA32, x64,
ARM32 and ARM64. Seven native comparisons per CPU cover unavailable and
populated process statistics, partial-alpha text and all five graph tabs.
ARM32 retains the consecutive variadic words used for 64-bit byte counts and
unit strings. IA32 shared formats relocate their byte-unit strings. ARM64
button and selector tail forwards are expressed as reviewed C calls.

These checks do not complete VM integration or release-wide compatibility.
