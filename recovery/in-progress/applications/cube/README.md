The 1.1 cube uses common C source on all four architectures. It preserves native
fixed-point projection, depth ordering, CPU and GPU rendering, theme colours,
frame lifecycle, keyboard exits and timeout argument parsing. Architecture
profiles include the shared C compiler and memory support.

The native comparisons exercise eleven lifecycle modes, sixteen timeout cases
and twelve guarded CPU raster cases per architecture. VM integration remains a
release validation requirement. Pooka's Free Software License applies.
