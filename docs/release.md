# Permafrost 0.7 recovery

The supplied 0.8 WinterFirmware and UEFI disks are the references for this
milestone. Only Permafrost 0.7 remains an active build target. Reference hashes
and architecture inventories are recorded in `recovery/reference.json`.

Both firmware paths, both CPU variants, the kernels, all three native VMs, and
bundled native utilities build from C/C++ source. Normal builds do not consume
reference executables, instruction blobs, NASM, or a decompiler installation.
Processor transitions use inline assembly inside C files; executable containers
and relocation tables are generated by the packaging tools.

The BIOS i386 kernel loads at 0x20000. The IA32 UEFI reference has the same
function offsets with a 0x1fe0000 address slide: all 4,606 changed address
operands account for the complete mapped-image difference. The EFI profile
shares the C implementation and supplies its relocated initialized data.
Both EFI CPU variants load their kernel at 0x02000000.

WMAP version 4 remains 124 bytes and moves to 0x6800. Service addresses and file/image wire pointers remain 32 bits on both CPUs.
Native callback values have 24-byte i386 and 40-byte LP64 x86-64 layouts. The SDK decodes native-width x86-64
service pointers before calls. Universal Mach-O and flat containers select the
matching architecture; the x86-64 VMs share the verified ILP32 C implementation.

Recovery corrections include variadic formatting, escaped stack storage,
XMM0/XMM1 geometry returns, floating-point bit views, operator token boundaries,
builtin-name lookup, line-buffer submission, EFI memory-map arguments, CPUID
subleaf/register handling, script return tags, numeric loop conversions, and
compiler-generated firmware-call bridges. EFI character and scan-code tables
are recovered data, replacing jumps into the reference instruction layout.

Validation covers hardware boots, public SDK allocation/file/PNG/status
services, relocated C/C++ SDK programs, native Lua/Rwby/WinterScript fixtures,
and comparison of x86-64 lexical and numeric behavior with the reference.
The bundled kernel WinterScript self-test passes on BIOS i386, IA32 UEFI,
and x86-64 UEFI. Direct comparison covers 20 token/scalar expressions and four
mathematical builtins. A separate output-directory build produces identical
images and SDK archives. These checks do not establish equivalence for every
program or physical hardware configuration.

WinterLua retains the reference's environment-ownership restriction on some
closure paths; this implementation is distinct from upstream Lua. The SDK is
freestanding and does not provide a hosted C++ library, RTTI, or exceptions
for newly developed native applications.
